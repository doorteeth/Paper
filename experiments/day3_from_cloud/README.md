# Day 3 — 从点云估计 γ，再写进因子

Day 2 把真实特征值直接交给因子。这一步只给 Day 1 的走廊点云：侧墙、地面、数量可变的端面。传感器偏航 35°，退化轴在世界系里不是坐标轴。

```bash
cd experiments/day3_from_cloud
python3 run_from_cloud.py
```

脚本在末尾做检查，全部通过时退出码为 0。图和数字在 `out/`。

水平平移信息来自 \(H=\sum nn^{\top}\)（点的位置噪声不进入法向）。转到世界系后

\[
\gamma_i=\frac{\lambda_i}{\lambda_i+\lambda_{\mathrm{imu}}}.
\]

因子沿特征方向使用的信息：IRR 用 \(\lambda_i\) 本身；硬切换在 \(\gamma\ge 0.3\) 时用健康轴的名义信息 960，否则用 0；sigmoid 用 \(w(\gamma)\times 960\)。

## 检查结果（50 次试验）

| 几何 | \(\gamma\) |
|---|---|
| 完整端面 | 0.992 |
| 两个端面点（灰色地带） | 0.500 |
| 纯走廊 | 0.000 |

纯走廊的最弱轴与隧道方向点积为 1.000。偏航 35° 之后，这个轴仍沿世界 \(+Y\)。

末端有回环、中间七步是灰色地带时，沿隧道的误差：

| | 固定协方差 | 硬切换 | sigmoid | 前端软融合、紧因子 | IRR |
|---|---:|---:|---:|---:|---:|
| 全程 ATE | 0.659 | 0.659 | 0.657 | 0.405 | 0.295 |
| NEES | 91 | 91 | 89 | 37 | 0.95 |
| 窗口之后的平均绝对误差 | 0.253 | 0.253 | 0.251 | 0.173 | 0.068 |

\(\gamma=0.5\) 已经过了硬阈值，所以硬切换和固定协方差是同一条曲线。sigmoid 在这里也饱和到名义信息。IRR 的 NEES 为 0.95。窗口之后，IRR 是硬切换的约四分之一，也低于“前端已经按 \(\lambda_i\) 融合、但因子仍按名义协方差发布”。

## 这一步结束时能说的话

从这组点云估计出的 \(\gamma\)，转回世界系之后，写进里程计因子，满足 Day 2 留下的判据：局部退化窗口之后的误差低于硬切换，也低于只在前端软融合。

测量仍是按 \(H\) 抽样的高斯，对应关系是已知平面法向，不是真实扫描匹配的迭代结果。机器人数据集上的前端不在这个实验里。
