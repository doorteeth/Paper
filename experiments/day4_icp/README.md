# Day 4 — 点到平面迭代的相对位姿

Day 3 的相对位姿是按信息矩阵抽的。这一步每步从 IMU 初值出发，对走廊平面做最近平面关联和高斯–牛顿更新。特征值不超过 \(10^{-6}\) 的方向不更新，停在初值上。因子使用收敛处的 Hessian，由雷达系旋到世界系。

```bash
cd experiments/day4_icp
python3 run_icp.py
```

通过时退出码为 0。图和数字在 `out/`。

传感器偏航 35°。点噪声标准差为 1，平面之间相距数十米，最近平面关联保持在生成该点的平面上。每个点对信息矩阵的贡献约为 1，因此两个端面点给出 \(\gamma=0.5\)，刚过硬阈值 0.3。

## 检查结果（50 次试验，诊断 200 次）

单步隧道方向平均绝对误差：

| IMU 初值 | 无端面 ICP | 两个端面点 | 完整端面 |
|---:|---:|---:|---:|
| 0.561 | 0.561 | 0.571 | 0.053 |

无端面时，ICP 与 IMU 在隧道轴上的差为 0。有符号偏差两者同为 \(-0.043\)。最弱轴与隧道方向的点积为 1。\(\gamma\)：完整端面 0.992，两个端面点 0.500，无端面 0。

中间七步为两个端面点、末端有回环：

| | 固定协方差 | 硬切换 | sigmoid | 前端软融合、紧因子 | ICP Hessian |
|---|---:|---:|---:|---:|---:|
| 沿隧道 ATE | 0.558 | 0.558 | 0.556 | 0.405 | 0.316 |
| NEES | 79 | 79 | 78 | 42 | 0.98 |
| 窗口之后的平均绝对误差 | 0.216 | 0.216 | 0.215 | 0.157 | 0.075 |

全程都是完整端面时，三种主要写法的沿隧道误差都是 0.113。

## 这一步说明的事

配准输出在不可观方向上就是 IMU 初值，不是零均值的配准噪声。\(\gamma=0.5\) 仍被硬切换当成健康扫描。把收敛 Hessian 写进因子后，窗口之后的误差低于前端紧因子，也低于硬切换；一致性接近 1。
